# data/

PDF files to ingest live here.

Drop one or more PDFs — engineering standards, datasheets, design guides —
directly into this directory, then run:

```bash
python -m src.ingest --data-dir data
```

## What gets tracked

This `README.md` is tracked in git so the folder structure exists for anyone
who clones the repo. **All other files in this directory are gitignored**
(see `.gitignore`) — keep confidential documents local.
